# Hydracraft

Hydracraft is a dependency-free Minecraft-inspired web client. It is designed to feel closer to the real Minecraft Java first-person experience than a bare canvas demo while staying easy to run locally.

## Defaults

- Minecraft Java version target: **1.18.2**
- Game mode: **Creative**
- Flight: enabled on spawn
- Spawn: a small creative platform above a generated overworld

## Controls

- Click **Play in browser** to lock the pointer.
- Move with `W`, `A`, `S`, and `D`.
- Look with the mouse.
- Hold `Ctrl` to sprint.
- Press `Space` to fly up and `Shift` to fly down.
- Press `F` to toggle creative flight.
- Left click breaks the targeted block.
- Right click places the selected block.
- Press `1` through `9` or scroll to select a hotbar slot.
- Press `R` to reset to the spawn platform.

## Development

```bash
npm run dev
```

Then open <http://localhost:5173>.

## Checks

```bash
npm run check
npm run build
```
